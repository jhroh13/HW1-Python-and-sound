# Android 빌드·실기기 검증

최신 SDK 빌드와 에뮬레이터 결과는 BUILD_STATUS.md를 참고하세요. 아래 실기기 테스트는 수행 계획이며 아직 통과 증거가 아닙니다.

1. JDK 17/Gradle 8.9/SDK 35에서 assembleDebug와 lintDebug 통과 확인.
2. Android 8, 12, 14, 15 기기 또는 에뮬레이터에 설치. Android 15 화면 인셋/버튼 접근 확인.
3. 최초 권한 허용, 거부, 다시 묻지 않음, 일회성 권한, 설정에서 권한 취소를 각각 확인.
4. 캡처 준비 직후 완료/취소, 짧은 캡처, 120초 캡처, 반복 시작/완료. OS 마이크 표시가 종료 시 꺼지는지 확인.
5. 다른 휴대폰 스피커와 현재 기기의 말소리/연주 녹음. 입력 레벨·음높이 갱신 확인.
6. 홈 이동, 화면 잠금, 통화/다른 앱의 마이크 사용, 외부 마이크 분리, 앱 종료 시 자원 해제 확인.
7. MP3, AAC/M4A, WAV, FLAC, OGG, 모노/스테레오, 44.1/48kHz 파일 및 손상/초과 길이 파일 선택.
8. 체크한 채널만 재생·저장되는지, 채널 레벨·0% 음소거, MIDI 합성음·WAV 믹스 내용 확인.
9. 로컬 저장소 및 지원되는 SAF 공급자에서 한글 제목 ZIP 저장, 저장 취소, 쓰기 실패 확인.
10. DAW에서 악기별/멀티트랙 MIDI 열기. 채널·음표 길이·velocity·GM program 및 드럼 채널 10 확인.
11. 회전 중 UI/프로젝트 유지, 앱 프로세스 종료 후 재시작 초기 상태, 메모리 부족 시 오류 안내 확인.

2.1 AI 기능은 다음도 실제 ARM64 휴대폰에서 확인합니다.

- 인터넷을 끈 상태에서 파일/마이크 분석과 MIDI 저장이 동작하는지 확인.
- 단일 악기와 전체 믹스 파일을 각각 분석하고 원본 MIDI가 있는 곡으로 pitch/onset/offset을 평가.
- 미분류 반주 기본값과 사용자가 지정한 악기 채널이 저장된 MIDI와 일치하는지 확인.
- 0초가 정렬된 베이스/피아노 분리 파일을 각각 추가한 후 선택한 트랙만 원음/MIDI/WAV로 출력되는지 확인.
- 길이가 다른 트랙, 같은 악기 교체, 파일 읽기 실패와 모델 오류 시 기존 프로젝트 유지 확인.
- 전체 믹스의 보컬이 채널 이름만으로 제거되지 않으며 화면의 지원 범위 설명과 실제 동작이 일치하는지 확인.
- 120초 입력의 처리 시간·메모리·발열을 기기별로 기록.

테스트 결과는 실행한 기기/OS 및 성공/실패를 기록한 뒤 CI 결과와 함께 PR에 첨부합니다. 현재 파일은 수행 계획이며 통과 증거가 아닙니다.
